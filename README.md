# Ferrum

## Что это

Ferrum — ваш личный ИИ-помощник. Вы пишете ему в Telegram, он отвечает и выполняет задачи.

Свою работу он делает в изолированной «песочнице» (закрытая среда, из которой нет доступа к вашим файлам). Доступ к одной вашей папке на Windows он получает только по вашей команде и спрашивает разрешение на опасные действия.

## Как установить

Что понадобится:

- Windows 11.
- Около 8 ГБ свободного места на диске, желательно 8 ГБ оперативной памяти.
- Аккаунт в Telegram.
- Доступ к ИИ-модели: её название и ключ (по умолчанию Ferrum ищет её по адресу `http://localhost:20128/v1`).

Установка занимает около получаса. Если не сказано иное, команды вводите в окне Ubuntu.

1. Установите Ubuntu внутри Windows. Откройте PowerShell от имени администратора и выполните:

   ```
   wsl --install -d Ubuntu-24.04
   ```

   Ожидаемый результат: Windows предложит перезагрузиться, а после этого Ubuntu попросит придумать имя пользователя и пароль.

2. Установите Node.js версии 24 (программа, на которой работает Ferrum). Откройте <https://nodejs.org/en/download>, выберите Linux и выполните показанные там команды. Затем проверьте:

   ```
   node -v
   ```

   Ожидаемый результат: `v24.` и дальше цифры.

3. Установите Ferrum:

   ```
   npm install -g --ignore-scripts @ironcarrier228/ferrum
   ```

   Ожидаемый результат: сообщение `added ... packages` без красных ошибок.

4. Проверьте компьютер:

   ```
   ferrum preflight
   ```

   Ожидаемый результат: список строк `[ OK ]`. Пока что допустимо одно `[FAIL]` про Docker: на следующем шаге вы его установите.

5. Установите Docker (программа для «песочницы»):

   ```
   ferrum install-docker
   ```

   Ожидаемый результат: Ubuntu покажет план, попросит ответить `y` и ввести пароль, который вы придумали на первом шаге.

6. Перезапустите Ubuntu. Закройте её окно, в PowerShell выполните команду ниже и снова откройте Ubuntu:

   ```
   wsl --terminate Ubuntu-24.04
   ```

   Ожидаемый результат: Ubuntu открывается как обычно.

7. Соберите «песочницу»:

   ```
   ferrum sandbox-image
   ```

   Ожидаемый результат: в конце сообщение об успешной сборке образа `ferrum-sandbox`.

8. Создайте бота в Telegram. Откройте в Telegram бота @BotFather, отправьте ему `/newbot` и ответьте на вопросы. Он пришлёт токен, длинную строку вида `123456:ABC...`. Свой номер аккаунта (число) покажет бот @userinfobot. Запишите оба значения и никому их не показывайте.

9. Запустите настройку:

   ```
   ferrum setup
   ```

   Ожидаемый результат: Ferrum по очереди спросит токен бота, ваш номер аккаунта, название модели и её ключ (ввод ключа и токена не виден на экране). В конце проверки пройдут без ошибок.

10. Проверьте, что всё готово:

    ```
    ferrum doctor
    ```

    Ожидаемый результат: одни `[ OK ]`, без `[FAIL]`.

## Как начать пользоваться

1. Запустите Ferrum:

   ```
   ferrum start
   ```

   Ожидаемый результат: в окне пойдут служебные строки, окно остаётся занятым. Не закрывайте его, пока пользуетесь помощником.

2. Подключите Telegram. Он уже подключён на шаге 9. Откройте в Telegram своего бота (название, которое вы ему дали) и нажмите «Запустить» (Start). Ожидаемый результат: бот открылся, ошибок нет. Отвечать он будет только вам.

3. Задайте первый вопрос. Напишите боту:

   ```
   Привет! Скажи слово ping
   ```

   Ожидаемый результат: через несколько секунд бот ответит словом `ping`.

4. Когда закончите, вернитесь в окно Ubuntu и нажмите Ctrl+C. Ожидаемый результат: Ferrum остановится, и бот перестанет отвечать, пока вы не запустите его снова.

Проверить, работает ли Ferrum, можно командой `ferrum status`. Список всех команд покажет просто `ferrum`.

Доступ к папке `D:\Ferrum` на Windows включается командой `/mode local` в чате с ботом. Подробности в `docs/`.

**Если что-то не работает.** Сначала запустите `ferrum doctor`: он подскажет, чего не хватает. Если на шаге 3 появилась ошибка `EACCES` (нет прав), выполните `npm config set prefix ~/.local` и повторите установку. Если бот молчит, проверьте, что окно с `ferrum start` открыто и что в Ubuntu работает `docker info`. Если не отвечает сама модель, проверьте её название, ключ и адрес. Другие случаи разобраны в папке [docs/](docs/).
